# Java Fundamentals Exercises
Self-contained programs to demonstrate core Java:
- ThePrimeNumberChallenge.java — loop & modulo (first five matches divisible by 3 and 5, sum)
- NumberOfDaysInMonth.java — leap-year logic + days-per-month using switch expression

## Run
Open in IntelliJ IDEA and run any file with `public static void main(String[] args)`.
Java 17.
